# Spellbook Trainer

Practice writing JavaScript functions as magic spells. Each spell asks for a function, you write it, and **Cast** runs trials to test it.

| Spell part | Code part |
|---|---|
| Incantation | Function name |
| Target / intensity / element | Parameters |
| Sequence of steps | Function body |
| Effect | `return` value |
| Base spell | Another function you call |

## Files

| File | What it holds |
|---|---|
| `index.html` | The page: layout, styles, and the code that runs the trials |
| `spells.js` | The list of spells. Add new spells here |

## Adding a spell

Copy an existing spell object in `spells.js`, give it a new `id`, change its request, hints and trials, and add it to the list.

## Notes
